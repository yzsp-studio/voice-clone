- 附带复用说明，指导安全的下游使用
- 明确不用于未经授权的模仿

## 🇬🇧 English

Creates a reusable cloned voice from a reference recording you are authorized to use. The workflow starts with consent, confirming scope and intended use, then reviews and optionally cleans the source recording and matches language and demo text before previewing. On acceptance it returns a consent record, recording check, cloned voice, preview sample, reuse guidance, and the acceptance result. It is explicitly not for unauthorized impersonation, and quality and compliance checks sit before generation rather than after.

### ✨ What it does

- Confirms consent scope and intended use before creating anything
- Reviews the reference recording and optionally cleans it
- Matches language and demo text so previews reflect the real target
- Returns a consent record, recording check, cloned voice, preview sample, and acceptance result
- Includes reuse guidance for safe downstream use
- Never clones a voice without authorization
